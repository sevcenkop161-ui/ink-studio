# Черновик кворка: «Разработка сайтов на Next.js под ключ»

Готовый текст для копирования в форму создания кворка на Kwork. Цены —
ориентир для старта, поправь под свой рынок (Kwork может иметь свой
минимум за кворк — проверь на странице создания).

## Категория

Программирование → Сайты под ключ (или «Веб-программирование», смотри,
что ближе в текущем меню Kwork).

## Заголовок

Вариант 1 (короче, под лимит символов):
> Разработаю сайт на Next.js под ключ — от лендинга до системы с бронированием

Вариант 2 (акцент на результат):
> Современный сайт на Next.js: быстрый, безопасный, с админкой и на 2 языках

Выбери тот, что влезает по символам в форму Kwork — обычно там жёсткий лимит,
Kwork сам подскажет остаток при вводе.

## Описание кворка

```
Делаю сайты на Next.js — от простого лендинга до полноценного сайта с
онлайн-записью, личным кабинетом и админ-панелью.

Не шаблон и не конструктор — код, который можно развивать дальше:
быстрая загрузка, корректная работа на телефоне, SEO из коробки.

ПРИМЕР РАБОТЫ — Ink Studio (сайт тату-студии, демо-проект):
🔗 Живой сайт: https://ink-studio-swart.vercel.app
🔗 Код открыт: https://github.com/sevcenkop161-ui/ink-studio

Что внутри этого примера — то же самое я могу сделать и для вас:
— Онлайн-запись с проверкой занятости в реальном времени (без двойных записей)
— Двуязычный интерфейс (RU/EN) с правильными URL для каждого языка
— Админ-панель с защищённым входом для управления контентом и заявками
— Уведомления в Telegram о новых заявках
— Адаптивная вёрстка, плавные анимации, тёмная тема

КАК РАБОТАЮ:

Стек: Next.js, TypeScript, Tailwind CSS, Supabase (база данных и

Пишите в личные сообщения с описанием задачи — отвечу и предложу, какой
```

## Тарифы

Kwork обычно просит 3 пакета. Черновик:

### Базовый — Лендинг
**Что входит:** одностраничный сайт (лендинг), адаптивная вёрстка под
телефон/планшет/десктоп, форма обратной связи (письмо на почту), базовое
SEO (заголовки, описание, картинка для соцсетей).
**Срок:** 3–5 дней
**Цена:** от 5 000 ₽ *(поправь под себя)*

### Стандарт — Сайт из нескольких страниц
**Что входит:** всё из «Базового» + до 5 страниц, двуязычность (RU/EN)
по желанию, анимации при скролле, интеграция с Telegram для заявок.
**Срок:** 7–10 дней
**Цена:** от 15 000 ₽ *(поправь под себя)*

### Премиум — Сайт с бэкендом (как Ink Studio)
**Что входит:** всё из «Стандарта» + база данных, онлайн-запись/бронирование
с проверкой занятости, админ-панель с защищённым входом, автоматические
тесты, деплой с автообновлением при изменениях.
**Срок:** 14–21 день
**Цена:** от 35 000 ₽ *(поправь под себя)*

> Цены — грубый ориентир для новичка на фрилансе. Посмотри цены похожих
> кворков в категории «Next.js» / «Разработка сайтов» на Kwork и
> скорректируй — если непонятно, ставь чуть ниже среднего для первых
> заказов и отзывов, потом поднимай.
