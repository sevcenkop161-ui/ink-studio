# Черновик кворка: «Разработка сайтов на Next.js под ключ»

Готовый текст для копирования в форму создания кворка на Kwork. Цены —
ориентир для старта, поправь под свой рынок (Kwork может иметь свой
минимум за кворк — проверь на странице создания).

## Категория

Программирование → Сайты под ключ (или «Веб-программирование», смотри,
что ближе в текущем меню Kwork).

## Что нужно от заказчика

Лимит 500 символов (используется весь):

```
Для старта работы понадобится:

— Кратко о задаче: что за бизнес, для кого сайт, какая цель (заявки, продажи, визитка)
— Список нужных страниц/разделов
— Тексты и фото, если уже есть (нет — помогу составить структуру, тексты можно доработать позже)
— Примеры сайтов, которые нравятся по стилю (2–3 ссылки)
— Домен и хостинг, если уже есть — иначе подскажу, что выбрать
— Логотип и фирменные цвета, если есть

Если что-то из этого пока не готово — не страшно, разберёмся вместе на созвоне/в переписке.
```

## Тарифы

Kwork обычно просит 3 пакета. Черновик:

### Базовый — Лендинг
**Что входит:** одностраничный сайт (лендинг), адаптивная вёрстка под
телефон/планшет/десктоп, форма обратной связи (письмо на почту), базовое
SEO (заголовки, описание, картинка для соцсетей).
**Срок:** 3–5 дней
**Цена:** от 5 000 ₽ *(поправь под себя)*

### Стандарт — Сайт из нескольких страниц
**Что входит:** всё из «Базового» + до 5 страниц, двуязычность (RU/EN)
по желанию, анимации при скролле, интеграция с Telegram для заявок.
**Срок:** 7–10 дней
**Цена:** от 15 000 ₽ *(поправь под себя)*

### Премиум — Сайт с бэкендом (как Ink Studio)
**Что входит:** всё из «Стандарта» + база данных, онлайн-запись/бронирование
с проверкой занятости, админ-панель с защищённым входом, автоматические
тесты, деплой с автообновлением при изменениях.
**Срок:** 14–21 день
**Цена:** от 35 000 ₽ *(поправь под себя)*

> Цены — грубый ориентир для новичка на фрилансе. Посмотри цены похожих
> кворков в категории «Next.js» / «Разработка сайтов» на Kwork и
> скорректируй — если непонятно, ставь чуть ниже среднего для первых
> заказов и отзывов, потом поднимай.
