# Черновик кворка: «Разработка сайтов на Next.js под ключ»

Готовый текст для копирования в форму создания кворка на Kwork. Цены —
ориентир для старта, поправь под свой рынок (Kwork может иметь свой
минимум за кворк — проверь на странице создания).

## Категория

Программирование → Сайты под ключ (или «Веб-программирование», смотри,
что ближе в текущем меню Kwork).

## Заголовок

Вариант 1 (короче, под лимит символов):
> Разработаю сайт на Next.js под ключ — от лендинга до системы с бронированием

Вариант 2 (акцент на результат):
> Современный сайт на Next.js: быстрый, безопасный, с админкой и на 2 языках

Выбери тот, что влезает по символам в форму Kwork — обычно там жёсткий лимит,
Kwork сам подскажет остаток при вводе.

## Технические поля формы

| Поле | Значение |
|---|---|
| Вид | Интернет-сервис |
| CMS | Самописная |
| Язык разработки | TypeScript *(своим вариантом — в стандартном списке его нет)* |
| Интерфейс на JavaScript | Да |
| Фреймворк JavaScript | React + свой вариант «Next.js» |
| Используется CSS | Да |
| Фреймворк CSS | Свой вариант «Tailwind CSS» *(в списке нет)* |
| База данных | Предусмотрена |
| Тип БД | PostgreSQL |

## Описание кворка

Финальный вариант, подогнанный под лимит 1200 символов (933 символа):

```
Делаю сайты на Next.js — от лендинга до сайта с онлайн-записью, личным кабинетом и админ-панелью.

Не шаблон и не конструктор — код, который можно развивать дальше: быстрая загрузка, адаптивная вёрстка, SEO из коробки.

Пример работы — Ink Studio (сайт тату-студии, демо-проект):
Сайт: https://ink-studio-swart.vercel.app
Код: https://github.com/sevcenkop161-ui/ink-studio

Что внутри — то же самое сделаю и для вас:
— Онлайн-запись с проверкой занятости в реальном времени
— Двуязычный интерфейс (RU/EN)
— Админ-панель с защищённым входом
— Уведомления в Telegram о заявках
— Адаптивная вёрстка, анимации, тёмная тема
— Автотесты и проверка безопасности

Как работаю: обсуждаем задачу → согласовываем структуру → разработка с промежуточными показами → тестирование → публикация на домене, передача доступов.

Стек: Next.js, TypeScript, Tailwind CSS, Supabase, Vercel.

Пишите в личные сообщения с задачей — подберу подходящий тариф.
```

## Что нужно от заказчика

Лимит 500 символов (используется весь):

```
Для старта работы понадобится:

— Кратко о задаче: что за бизнес, для кого сайт, какая цель (заявки, продажи, визитка)
— Список нужных страниц/разделов
— Тексты и фото, если уже есть (нет — помогу составить структуру, тексты можно доработать позже)
— Примеры сайтов, которые нравятся по стилю (2–3 ссылки)
— Домен и хостинг, если уже есть — иначе подскажу, что выбрать
— Логотип и фирменные цвета, если есть

Если что-то из этого пока не готово — не страшно, разберёмся вместе на созвоне/в переписке.
```

## Тарифы

Реальная форма Kwork использует фиксированные названия «Эконом / Стандарт /
Бизнес» и свой набор чекбоксов (не текстом, а конкретными опциями). Ниже —
то, что реально ушло в форму.

### Краткое описание пакета (лимит 120 символов)

**Эконом** (98 симв.):
```
Лендинг: адаптивная вёрстка, форма обратной связи, базовое SEO. Готовый сайт под ключ за 3-5 дней.
```

**Стандарт** (98 симв.):
```
Сайт из нескольких страниц: форма заявок, SEO, двуязычный интерфейс (RU/EN), анимации при скролле.
```

**Бизнес** (105 симв.):
```
Сайт с базой данных: живая онлайн-запись, защищённая админ-панель, автотесты. Как в примере — Ink Studio.
```

### Срок выполнения
Эконом — 5 дней · Стандарт — 10 дней · Бизнес — 20 дней

### Цена

Kwork ограничивает диапазон цены выпадающим списком (не свободный ввод) —
судя по стартовым значениям (400₽ / 800₽ / 1200₽) и обрезанному максимуму
(~10 800₽), это лимит для нового продавца без рейтинга, а не «правильная»
рыночная цена. Реально выставили:

- **Эконом — 2 800 ₽**
- **Стандарт — ~6 000 ₽**
- **Бизнес — ~9 600–10 000 ₽** (ближе к верхней границе — это флагманский
  пакет, там реально в разы больше работы)

По мере роста рейтинга и отзывов лимит обычно снимается — тогда можно
поднимать цены ближе к рыночным (для такого объёма работы, как в
Стандарт/Бизнес, это скорее 15 000–35 000 ₽).
