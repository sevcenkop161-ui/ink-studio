# Материалы для Кворка

*(по пункту 38 ТЗ — `PROJECT_SPEC.md`)*

**Название кейса:** Ink Studio — Premium Tattoo Studio Website

**Краткое описание:**
Современный сайт тату-студии с каталогом мастеров, галереей работ,
услугами и системой онлайн-записи.

**Что демонстрирует проект:** UI/UX, frontend, responsive design,
animations, database, forms, booking system, deployment.

> **Важно:** в портфолио честно указывать «Демонстрационный концепт-проект».
> Это не работа реального клиента, а проект для портфолио, где стек и
> функциональность настоящие, а бизнес — вымышленный.

---

## Развёрнутый текст (для описания кейса на Kwork)

```
Ink Studio — двуязычный (RU/EN) сайт тату-студии с полноценной онлайн-
записью и админ-панелью. Демо/концепт-проект для портфолио: студия
вымышленная, но весь стек, база данных, бронирование и защита данных —
настоящие, рабочие, как в боевом проекте.

Живой сайт: https://ink-studio-swart.vercel.app
Код открыт: https://github.com/sevcenkop161-ui/ink-studio

Что реализовано:
— Каталог мастеров с индивидуальными страницами
— Галерея работ с фильтрацией по стилю
— Онлайн-запись в 6 шагов с проверкой занятости в реальном времени
  (двойная запись физически невозможна — это гарантирует база данных)
— Админ-панель с защищённым входом для управления заявками
— Уведомления в Telegram о новых заявках
— Адаптивная вёрстка, анимации, тёмная тема

Технологии: Next.js, TypeScript, Tailwind CSS, Supabase, Vercel.
```
