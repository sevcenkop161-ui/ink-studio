# Ink Studio — кейс для портфолио

**Живой сайт:** https://ink-studio-swart.vercel.app
**Код:** https://github.com/sevcenkop161-ui/ink-studio

## Что это

Ink Studio — двуязычный (RU/EN) сайт тату-студии с полноценной онлайн-записью
и админ-панелью. Демо/концепт-проект для портфолио: студия вымышленная, но
весь стек, база данных, бронирование и защита данных — настоящие, рабочие,
как в боевом проекте.

## Что решает сайт

- **Онлайн-запись без звонков.** Клиент сам выбирает услугу, мастера, дату
  и время — доступность времени подтягивается из базы в реальном времени,
  двойная запись на один слот физически невозможна (это гарантирует сама
  база данных, а не только фронтенд).
- **Двуязычность не "для галочки".** Не Google Translate поверх интерфейса —
  отдельные тексты для каждого языка, корректные URL (`/ru/...`, `/en/...`),
  правильные `hreflang`-теги для поисковиков.
- **Админ-панель для владельца студии.** Вход по логину/паролю, управление
  мастерами, услугами и заявками на запись — без доступа к коду или базе
  напрямую.
- **Уведомления в Telegram** о каждой новой заявке — не нужно проверять
  админку вручную.

## Технический стек

Next.js 16, TypeScript, Tailwind CSS v4, Supabase (Postgres + Auth), Vercel.

## Что это показывает как разработчика

- **Полный цикл**, а не только вёрстка: от базы данных и авторизации до
  деплоя и мониторинга безопасности
- **Безопасность на уровне базы данных** (Row Level Security), а не только
  проверки в коде — даже если обойти фронтенд, данные защищены
- **SEO и доступность** проверены реальными автоматическими инструментами
  (Lighthouse-класса аудит, axe-core), а не "на глаз"
- **Производительность:** публичные страницы отдаются статически с
  фоновым обновлением, а не пересобираются на каждый запрос
- **Тесты** — модульные и end-to-end, включая реальный сценарий записи и
  проверку доступности интерфейса
- **Настоящий деплой** с автоматическим обновлением при каждом изменении
  кода (CI/CD через Vercel + GitHub)
